# 搬瓦工 VPS 入门：套餐选择、首次连接与常见用途

## 先确定用途，再选择服务器

搬瓦工是什么？BandwagonHost 提供 VPS（虚拟专用服务器）：用户租用一部分服务器资源，安装和管理自己的操作系统。KiwiVM 是其管理面板，用来查看连接信息、控制电源、重装系统和管理备份；进入系统后，则通常通过 SSH 在命令行中操作。它不是买来就能直接使用的网站或应用，软件安装、账户安全和数据维护都需要自己负责。

选购前先列出任务。练习 Linux 命令和运行小脚本，可以从较小的配置开始；搭建个人网站时，还要考虑数据库、网站文件和访问流量；部署 Dify 等应用则应先核对应用当前的资源要求，以及模型服务是否需要额外账户和费用。即使同为网站，内容规模、访问量和插件数量不同，资源需求也会不同。

面向哪里的访问者也会影响选择。搬瓦工 CN2 GIA 及 GIA-E 是参考资料中用于区分线路的名称，而机房位置、可选线路和费用需要结合具体套餐查看。比较时不要只看内存：CPU 核数影响可用计算资源，磁盘要容纳系统和数据，月流量涉及数据传输额度，计费周期决定一次付款覆盖的时间。带宽标称值不是实际下载速度，实际访问情况还取决于用户网络和具体使用时段。

## 购买后首次连接

登录账户后，依次进入 **Services → My Services**，在对应服务旁打开 **KiwiVM Control Panel**。搬瓦工控制面板首页的 **Public IP address** 是服务器公网地址，**SSH Port** 是连接端口；端口应以面板显示的值为准，不要假设一定是 22。

首次设置密码时，确认 VPS 已开机，在左侧选择 **Root password modification**，点击 **Generate and set new root password**。参考资料说明新密码会发送到注册邮箱。妥善保存邮件和密码，不要把它们发布到公开页面，也不要与不需要管理权限的人共享。

Windows 可用 PowerShell 或 SSH 客户端，macOS 和 Linux 可使用终端。下面是 Bash 命令：先在终端中将环境变量 `SERVER_IP` 和 `SSH_PORT` 分别设为面板中看到的地址和端口，再运行：

```bash
ssh -p "$SSH_PORT" "root@$SERVER_IP"
```

PowerShell 用户设置好同名环境变量后，可运行 `ssh -p $env:SSH_PORT "root@$env:SERVER_IP"`。提示认证时输入设置好的 root 密码。连接成功后就进入服务器命令行；服务器上的操作具有管理权限，执行命令前应先理解其作用。日常维护时保护账户、邮箱和面板入口与保护 SSH 密码同样重要。

## 用 VPS 学习 Linux

如果准备从干净系统开始，KiwiVM 的 **Install new OS** 可用于选择并重新安装系统。先确认选中的是正确的 VPS，再选择面板提供的系统并确认操作。**重装会覆盖现有系统**，已有网站、数据库或其他重要文件时，应先完成备份并确认可以恢复。新密码按面板提示获取。

连接后可以从查看状态开始，而不是立即安装大量软件。以下示例中，`apt` 更新命令适用于 Ubuntu、Debian 等使用该包管理器的系统；其他发行版应使用相应工具。更新会改变已安装的软件包，执行前尤其要注意生产环境的兼容性。

```bash
# 更新软件包索引并升级已安装的软件包
apt update && apt upgrade -y

# 查看内核和发行版信息
uname -a
lsb_release -a

# 查看磁盘、内存和进程
df -h
free -h
top
```

`df -h` 有助于发现磁盘空间不足，`free -h` 可查看内存使用，`top` 则用于观察正在运行的进程。练习时先理解输出，再决定是否需要调整服务。若暂时无法使用本地 SSH 客户端，也可查看面板是否提供 **Root shell – basic**，通过浏览器进入命令行。

## 个人建站与应用部署

### 从运行环境到 WordPress

搬瓦工建站需要的不只是 VPS：还要有运行网站的软件、存放内容的数据库，以及网站程序本身。宝塔面板提供图形化管理方式；LNMP 指 Linux、Nginx、MySQL 和 PHP 组成的运行环境；WordPress 则是用于管理网站内容的程序。三者各司其职，安装面板并不等于网站已经建成。

参考资料提供了 Ubuntu/Debian 上安装宝塔的命令。执行远程安装脚本前，应先了解脚本来源和内容，并确认适用于所选系统：

```bash
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && bash install.sh ed8484bec
```

安装后记录面板显示的访问地址和管理员凭据，保护好这些信息。进入面板后，可按以下顺序进行：

1. 安装 LNMP 环境，等待相关服务安装完成。
2. 在“网站”中添加站点，填写用于访问的域名或 IP，并创建数据库。
3. 通过文件管理器上传 WordPress 安装包，或使用面板提供的 WordPress 安装功能。
4. 按安装界面填写数据库信息并完成站点初始化；随后检查站点访问和管理入口，保存好数据库凭据。

网站上线后，内容、数据库和配置都值得纳入备份。更换系统或调整环境之前，先确认备份覆盖了需要保留的内容，避免只保存网页文件而遗漏数据库。

### 以 Docker 部署 Dify

Dify 可用于构建 AI 应用。参考资料给出的流程是使用 Docker 和 Docker Compose 运行项目，再在设置中接入模型提供商。部署前应核对 Dify 当前文档、系统兼容性与资源要求；表中的 GIA-E 2GB 是可供比较的方案，并不保证满足当前版本或实际工作负载。

1. 在服务器上准备 Docker 和 Compose，确认两者可正常使用。
2. 从 [Dify 项目仓库](https://github.com/langgenius/dify.git)取得代码，进入项目的 `docker` 目录。
3. 按项目文档复制示例环境配置，检查并调整所需设置，然后启动服务。
4. 服务启动后访问初始化页面，在设置中选择模型提供商并填写所需的 API Key，再按需求创建应用。

参考资料中的基本启动命令如下；不同版本的配置和步骤可能变化，应以项目当前文档为准：

```bash
git clone https://github.com/langgenius/dify.git
cd dify/docker
cp .env.example .env
docker compose up -d
```

自行部署应用并不意味着所有数据都留在这台 VPS 上：接入外部模型时，需了解所选服务的数据处理方式、凭据管理及可能产生的费用。不要把 API Key 写进公开仓库，调整环境配置前也应保留必要的备份。

## KiwiVM 日常管理与排查

**Main controls** 提供开机、关机和重启操作。需要维护系统时，先确认当前服务状态，避免在任务运行中直接关机。面板中的 **Snapshots** 可用于手动创建快照，**Automatic Backups** 可用于自动备份；快照和备份是恢复手段，操作前应了解面板中可用的选项，并确认重要数据能被恢复。

**SSH Keys** 可用于上传公钥，供后续登录使用；私钥应保存在自己控制的设备上。需要迁移机房时，可查看 **Migration** 中与当前套餐对应的可用选项。迁移前先备份，完成后检查 IP 是否变化，并相应检查站点和连接配置；可选目的地和费用以面板显示为准。

SSH 连接失败时，先在面板确认服务器处于开机状态，再逐项核对公网 IP、SSH 端口、用户名和认证信息。若连接信息无误但仍无法连接，可查看面板是否提供 **Check if my IP is banned** 检测工具，结合结果继续排查。不要在尚未确认原因时立即重装：重装会覆盖系统，也未必能解决网络或认证问题。
